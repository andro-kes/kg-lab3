# Лабораторная № 3. Текстурирование

Запустите `build.cmd --offline`, затем `run.cmd`. Для сборки используются инструменты и зависимости из соседней папки `lab1`.

В разделе **Object and material** списки **First cone** и **Second cone** выбирают материалы независимо. Доступны **Mona Lisa**, **Spiral**, **Shark** и **Doge**. У **Mona Lisa**, **Shark** и **Doge** есть только карта альбедо. Для блика и свечения привязана общая чёрная текстура 1×1. У **Spiral** три карты. Светлые участки specular-карты дают блик, а бирюзовые линии emissive-карты видны даже при выключенном освещении.

**Animate first texture** включает на первом конусе смешивание двух выборок одной текстуры. У второй выборки меняются масштаб и смещение относительно первой, цвет модулируется по времени. Второй конус удобен для сравнения при одинаковом материале. Чтобы отдельно увидеть свечение, выставьте в ноль интенсивности фонового, направленного, точечных и прожекторных источников и отключите маркеры света.

UV боковой поверхности идут по окружности и высоте, основание использует плоскую проекцию. Оба конуса используют одну геометрию в памяти устройства и один динамический uniform-буфер моделей. Перед рисованием каждого конуса выбираются набор дескрипторов материала и выровненное смещение модели. Фрагментный шейдер получает время и флаг эффекта через push-константы.
